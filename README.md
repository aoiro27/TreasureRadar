# しきしろレーダー

しきしろを探すための、受信側 iPhone アプリです。隠したスマホが出す Bluetooth / iBeacon の電波の強さに応じて、レーダーの点と「ピピッ」という音が近づくほど反応します。

Bluetooth は距離の目安は取れますが、方角までは分かりません。点の位置ではなく、中央に寄るほど近い、音が速くなるほど近い、という使い方です。

このアプリ同士で探しているときは、数メートルまで近づくと UWB（超広帯域無線）に切り替わり、赤い点が本物の方角を指します。UWB が切れたら、また Bluetooth の距離表示に戻ります。

## 必要なもの

- 探す側: iPhone（iOS 17 以降）とこのアプリ
- 隠す側: Beacon Simulator などを入れたスマホ、またはもう1台の iPhone（このアプリの「かくす」）

シミュレータでは本物の電波は取れません。動き確認には設定の「れんしゅう」モードを使ってください。

## 使い方

1. Xcode で `TreasureRadar.xcodeproj` を開き、自分の Team を選んで実機に入れます。
2. 発信側を **iBeacon** にし、次の UUID をそのまま使います。

```
D4A60A10-7EA5-4E12-9ADA-545245415355
```

Major / Minor は `1` / `1` がかんたんです。アプリ内の「せってい」と同じ値にしてください。
3. 発信をオンにしたまま、隠す側のスマホを隠します。
4. 探す側で「さがす」を押し、位置情報と Bluetooth を許可します。
5. 赤い点が中央に寄り、音の間隔が短くなったらすぐそばです。「まだとおいよ」「ちかづいてきたよ」などの声でも知らせます。

声は `TreasureRadar/Sounds/` の `voice_*.wav` です。同じファイル名で差し替えてビルドすれば、自分で録った声に変えられます。詳細は `TreasureRadar/Sounds/README.md` を見てください。

iPhone 同士なら、隠す側で「かくす」を押せば Beacon Simulator なしでも発信できます。画面ロックで発信が止まることがあるので、隠す側は充電しながら画面をつけたままが安心です。

nRF Connect などで名前付きの BLE 発信にする場合は、設定のさがし方を「Bluetoothのなまえ」に変えて、同じ名前を入れてください。

## 注意

- 実機が必要です。
- iOS は iBeacon を Core Location で測距します。UUID が違うと反応しません。
- 壁や体で電波は弱くなるので、まずは広い部屋で試すと分かりやすいです。
- 方位レーダー（UWB）は UWB 対応の iPhone 同士で、かくす側もこのアプリを開いているときだけ使えます。初回は付近の機器とローカルネットワークの許可が必要です。
